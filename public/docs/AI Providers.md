# AI Providers

Taskyon aims to be AI inference agnostic. This means all of its features should work
with every provider which offer chat completion.

## Taskyon keys

- there are three types of keys that taskyon can work with:
  - TYT: taskyon.space authentication token
  - TYPK: taskyon.space restricted API keys which can be generated by the user (and which can be used on public webpages!).
    - FK: Taskyon provides a free, public API key to everyone as long as they don't misuse the key.
  - AK: any other 3rd party API key. They are stored safely in taskyons "secretStore" encrypted with the session key and not in the cloud.

- Authenticate to Taskyon.space:
  - change to encrypted user session
    - check what key was last used in user session
      - if TYPK use that
      - if no TYPK, use TYT
- logout from taskyon.space:
  - change session to "default"
    - check what key was last used in "default" session.
